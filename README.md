## BinyamFS Edition HUD for Courseplay

An unofficial companion that gives Courseplay a clean SAM-style HUD, consistent button spacing, compact vehicle names, custom names and implement names. Hold **Left Alt** while hovering over the HUD for tooltips.

Install `FS25_z_CourseplayBinyamFS.zip` alongside [official Courseplay](https://github.com/Courseplay/Courseplay_FS25/releases), enable both mods, and select **BinyamFS Edition** in Courseplay User Settings. Courseplay remains independently updateable. Version **1.0.1.1** aligns the remaining-time text with the Nearest Waypoint row without a button background or border.

The companion is licensed under GPLv3. Its folder includes the full license, credits, preferred source archive, checksums, and passing GIANTS TestRunner report. It is free to download and is not endorsed by Courseplay or GIANTS Software. Future companion updates are maintained here; the former private development repository is archived.
