# 1.0.0.8

Documentation update: clarify AutoDrive's vehicle and editor mode requirement for node visibility. Parking behavior is unchanged from 1.0.0.7.

- Keep the row target on terrain when pointing across painted line placeables or into buildings.
- Render row guides and markers on top of surfaces, including floors and roofs, without raising node coordinates onto roofs.
- Verified in game: painted guide alignment, placement inside shed bays, and secondary parking nodes with AutoDrive 3.0.1.2.

To see the placed nodes, you must be in a vehicle with AutoDrive's **editor mode** enabled. This is required by AutoDrive for node visibility.
