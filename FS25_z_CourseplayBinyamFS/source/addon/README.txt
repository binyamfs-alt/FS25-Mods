BinyamFS Edition HUD for Courseplay — GPLv3 companion

Install FS25_z_CourseplayBinyamFS.zip alongside the original FS25_Courseplay.zip.
Enable both mods, then choose Courseplay settings > User Settings > HUD skin >
BinyamFS Edition. The standard Courseplay appearance remains the default.

Update Courseplay normally. This companion does not contain or replace its files.
Disable the companion to return to the official HUD without changing Courseplay.
The companion must be installed/enabled on the server and clients for multiplayer.

A smaller second line shows the saved vehicle nickname on the left and attached
implements on the right. Empty names/attachments leave that side blank.

Controls use equal column widths, compact +/- buttons, wider value fields and
toolbar cells without hidden-button gaps. Hold Left Alt while hovering to see its destination or action. Release Alt to hide
the tooltip. Left Alt only activates tooltips over the visible CP HUD. Game-bound shortcuts
are isolated during tooltip mode and restored on release or pointer exit. Mods
reading the physical key directly may still respond.

Features: subtly rounded buttons, SAM styling, uniform body/header text, capitalized selections, compact
vehicle names, full-name hover tooltip, and one-screen-pixel button borders.

Interface checks target Courseplay 8.1.0.3. Future CP interface changes may require
a companion update. In-game rendering and interaction still need verification.

Courseplay is developed by Courseplay.devTeam and contributors. This is an
unofficial companion, not an endorsed or official Courseplay release.
